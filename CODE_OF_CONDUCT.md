# Code of Conduct

schedkit follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

It applies to every schedkit space: GitHub repositories, issues, pull requests
and Discussions, chat channels, meetings, and events where people represent the
project.

## Reporting

If you experience or witness behavior that violates the Code of Conduct,
please report it privately. You can contact:

- A maintainer listed in [MAINTAINERS.md](./MAINTAINERS.md) directly; or
- the CNCF Code of Conduct Committee at **conduct@cncf.io**, in particular if
  the report involves a schedkit maintainer, or if you'd rather not talk to the
  maintainers.

Reports are handled confidentially. Maintainers involved in a report, as the
reporter or the subject, step back from handling it.

## Enforcement

Maintainers are responsible for enforcing the Code of Conduct in schedkit
spaces. Responses range from a private note to a temporary or permanent ban
from project spaces. Incidents that maintainers can't resolve, or that involve
maintainers, are escalated to the CNCF Code of Conduct Committee.
