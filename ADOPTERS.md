# schedkit adopters

This is a list of organizations and projects that use schedkit (schedctl,
sked or the scheduler catalog). If you use schedkit, we'd love to hear about
it — it helps the project, and it helps other people decide whether schedkit
fits their needs.

## Adding yourself

Open a pull request adding a row to the table below, keeping it in
alphabetical order. Tell us what you use and how, in a sentence or two.
Production, staging, CI and lab usage are all welcome; just say which.

If you'd like to be listed but can't open a pull request, open a
[Discussion](https://github.com/orgs/schedkit/discussions) and a maintainer
will add you.
