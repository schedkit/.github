# schedkit maintainers

This file lists the maintainers of the schedkit project. It applies to every
repository in the [schedkit GitHub organization](https://github.com/schedkit)
unless a repository has its own `MAINTAINERS.md` that says otherwise.

How someone becomes (or stops being) a maintainer is described in
[GOVERNANCE.md](./GOVERNANCE.md).
